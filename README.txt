JAIDEE PRINTING - ชุดเว็บไซต์โปรแกรมคำนวณสติ๊กเกอร์ชิ้นใหญ่

ไฟล์สำคัญ
- index.html              หน้าโปรแกรมหลัก
- manifest.webmanifest    ข้อมูลติดตั้งเป็นเว็บแอป
- sw.js                   ใช้งานซ้ำ/ออฟไลน์หลังเปิดครั้งแรก
- icons/                  ไอคอนเว็บไซต์และ Add to Home Screen
- netlify.toml            ตั้งค่าสำหรับ Netlify
- .nojekyll               ใช้กับ GitHub Pages

วิธีลง Netlify
1) แตกไฟล์ ZIP
2) เข้า Netlify > Add new site > Deploy manually
3) ลากทั้งโฟลเดอร์ jaidee_large_sticker_website เข้าไป
4) รอระบบสร้าง URL แล้วเปิดใช้งานได้ทันที

วิธีลง GitHub Pages
1) สร้าง Repository ใหม่
2) อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไว้ที่ root ของ repository
3) ไปที่ Settings > Pages
4) Source: Deploy from a branch
5) เลือก Branch: main และ Folder: /(root) แล้ว Save
6) รอ GitHub สร้าง URL ให้

iPhone/iPad
- เปิดเว็บด้วย Safari > Share > Add to Home Screen

Android
- เปิดเว็บด้วย Chrome > เมนู > Add to Home screen / Install app

PC
- Chrome/Edge สามารถกด Install app จากแถบที่อยู่หรือเมนูเบราว์เซอร์ได้
